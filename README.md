# 📰 Projet EMC : La Liberté de la Presse

Un site web interactif et immersif présentant un dossier de recherche complet sur la liberté de la presse, son rôle démocratique et ses défis actuels. Ce projet a été réalisé dans le cadre du cours d'Enseignement Moral et Civique (EMC).

## ✨ Fonctionnalités Premium
- **Design Éditorial** : Mise en page "premium" inspirée des grands journaux (NYT style) avec typographie soignée et lettrines.
- **Navigation Intuitive** : Menu latéral escamotable pour un accès fluide aux 6 sections thématiques.
- **Recherche interactive** : Barre de recherche avec surlignage des résultats en temps réel (style Ctrl+F).
- **Expérience Immersive** : Animations scrollytelling (fondu au défilement) et illustrations thématiques générées sur mesure.
- **Documentation** : Bibliographie intégrée avec accès direct aux ressources institutionnelles (RSF, ARCOM, Amnesty, etc.).

## 🚀 Utilisation
Pour visualiser le projet, il suffit d'ouvrir le fichier `index.html` dans un navigateur web (Chrome, Safari, Firefox).
